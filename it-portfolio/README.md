# IT Portfolio Website

A simple responsive IT portfolio website using HTML, CSS, and JavaScript.

## Folder structure

- `index.html` — main portfolio page
- `css/style.css` — styling and responsive layout
- `js/script.js` — small JavaScript enhancement
- `assets/profile.jpg` — uploaded profile photo

## How to use

1. Open `index.html` in a browser.
2. Replace `Your Name` with your name.
3. Update the About Me text, skills, projects, email, GitHub, and LinkedIn links.
4. Upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting service.

No build tools are required.
